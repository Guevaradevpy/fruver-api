# 🥑 Fruver Management API

**Fruver API** is a **RESTful API** designed to manage **inventory control, product flow, and financial tracking** for businesses that handle stock and product dispatch.

Although it is especially suited for food-related businesses such as fruit and vegetable stores (*fruver*), minimarkets, or small restaurants, the system is **flexible enough to be used by any inventory-based business** that requires structured stock and money control.

---

## 🎯 Project Purpose

Many small and medium-sized businesses struggle with:

- Poor inventory control  
- Unclear product inflow and outflow  
- Financial losses caused by disorganized stock management  
- Difficulty scaling due to lack of reliable data  

**Fruver API** aims to solve these problems by providing a **clean, scalable, and backend-focused foundation** that allows businesses to grow with confidence and control.

This project is built with **long-term scalability** in mind, not as a quick prototype.

---

## 🧠 Core Features (Initial Version)

- REST API built with **FastAPI**
- Inventory and product flow management
- Basic budget and profit tracking
- Layered architecture for maintainability and scalability
- Authentication using **JWT**
- Data validation with **Pydantic**
- Persistent storage with **MySQL**
- ORM integration using **SQLAlchemy**
